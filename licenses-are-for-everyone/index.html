Licenses 101

Code can usually flow toward more obligations. Rarely back.
MIT app + GPL-3.0 dependency
Ship it as a binary and the combined work goes out under GPL-3.0 terms. Fine if you meant it; a surprise if you didn't.
Apache-2.0 + GPL-2.0-only
Incompatible: Apache's patent terms add conditions GPL-2.0 doesn't allow. GPL-3.0 fixed that.
Licenses 101
Four things we tell ourselves
“It's on GitHub, so it's free.”
Public isn't licensed. No license means all rights reserved.
“We only use it internally.”
Until you ship an app, a binary or a container. AGPL counts network users too.
“I checked my dependencies.”
The direct ones. Transitive dependencies bring their own licenses.
“Legal will catch it.”
Usually at release, fundraising or acquisition: the most expensive moment to find out.
Why you should care
If you ship code, licenses are your job too
Maintainers
Choose your license on purpose, and check your dependencies allow it.
Engineers
“No AGPL” is company policy. You're the one typing the install command.
Founders
Due diligence asks for a license inventory, usually at fundraising or acquisition.
Students
Attribution is how open source pays its people. Keep the notices.
Whoever adds the dependency owns the license question. Legal only sees it later.

Meet Feluda
A detective for your dependency tree
A Rust CLI that reads your dependencies, notes each license, and flags anything restrictive or incompatible with your project's license. MIT licensed, v1.16.
# install · also on AUR, pkgsrc, .deb, .rpm $ cargo install feluda $ brew install feluda
# then, inside your project $ feluda
Meet Feluda
How Feluda solves the case
Detect
Finds the manifests and lockfiles in your project.
Read locally
node_modules, Cargo.toml and package caches first.
Ask upstream
Registries and the GitHub API, cached for 30 days.
Fill gaps
Unresolved ones go to ClearlyDefined in one batch.
Judge
Restrictive list, compatibility matrix and OSI status.
Then it reports: a table, JSON, YAML, SARIF, or a non-zero exit code that fails the build.

Use it · 2 of 4
Write your policy down, once
feluda init writes a .feluda.toml and a pre-commit hook.
  • Defaults flag GPL, AGPL, LGPL-3.0, MPL-2.0, EPL-2.0 and CC-BY-SA-4.0
  • Override that list, ignore licenses, or skip whole dependencies
  • Custom rules name bespoke license texts
  • Environment variables beat the file; the file beats defaults
# .feluda.toml [licenses] restrictive = ["GPL-3.0", "AGPL-3.0"] ignore = ["MIT", "Apache-2.0"] [[licenses.custom]] id = "LicenseRef-acme-internal" match_all = ["ACME CONFIDENTIAL"] restrictive = true
